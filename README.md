# cathzhou.github.io

My personal website: <https://cathzhou.github.io>

Plain HTML, no build step. Pushing to `master` deploys it to GitHub Pages.

- `index.html`, `research/index.html`, `things/index.html`: the three pages. Edit the text directly.
- Green links with `data-description` expand a short blurb underneath when clicked (`script.js`).
- `glass.js`: the stained glass. The home page window turns `img/loaf.png` into glass (click a pane to recolor, RE-LEAD for a new pattern, HOLD TO PEEK for the photo); the other pages get a glass strip at the bottom. It also draws the rose-window logo and the drifting colored light. Jewel colors are `JEWELS` at the top.
- `styles.css`: page styles. Link colors cycle through `JEWEL_TEXT` in `script.js`.
- `img/`, `files/`: photo and resume.
