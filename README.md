# cathzhou.github.io

My personal website: <https://cathzhou.github.io>

Plain HTML, no build step. Pushing to `master` deploys it to GitHub Pages.

- `index.html`, `research/index.html`, `things/index.html`: the three pages. Edit the text directly.
- Colored links with `data-description` expand a short blurb underneath when clicked (`script.js`).
- `glass.js`: the stained glass. The whole page background is a leaded glass window that lights up under the cursor; click a pane to recolor it, RE-LEAD for a new pattern, RESET for the original colors. The text sits on a clear arched pane in the middle. It also draws the rose-window logo, the leaded strips under section headings and the colored light on the pane. Colors are `JEWELS` and `PALETTE` at the top.
- `styles.css`: page styles. Link colors cycle through `JEWEL_TEXT` in `script.js`.
- `files/`: resume.
